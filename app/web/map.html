Why it's shaped this way

  • AI talks, code decides. Riya and Gemini only collect what the caller said. The verdict comes from the five checks in code (step 7), so a persuasive caller can't talk a model past a rule.
  • No price ever leaves the system. Price floors live only in the backend rules; the agent's brief has none (a test checks it), and every transcript is scanned for prices after the call.
  • Two front doors, one brain. Phone and website conversations meet the same rules and the same dashboard.
  • Call backs, not transfers. Riya never puts a call through; she promises a call back and the team gets a private request with the number.
  • Public, but private where it matters. The dashboard is open without a login, so it never shows a phone number or email address.

Not in this build: WhatsApp and the web form. They would join at step 7 with the same checks.
